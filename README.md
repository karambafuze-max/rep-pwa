# REP — PWA для тренировок

Первая рабочая версия приложения.

## Что уже есть
- неограниченное количество шаблонов тренировок;
- одну и ту же тренировку можно запускать сколько угодно раз;
- создание тренировки из списка упражнений;
- 18 упражнений в стартовой базе;
- подходы, вес и повторения;
- копирование результатов последнего выполнения упражнения;
- история завершённых тренировок;
- календарь с ручными заметками и 8 цветами;
- автоматическая точка в календаре в дни завершённых тренировок;
- таймер отдыха 90 секунд;
- локальное хранение данных на устройстве;
- офлайн-режим после первого открытия;
- установка на домашний экран iPhone как PWA.

## Как запустить на Mac для проверки
В Terminal:

```bash
cd rep-pwa
python3 -m http.server 8080
```

После этого открыть на Mac: http://localhost:8080

## Как бесплатно установить на iPhone
PWA должна открываться по HTTPS. Самый простой бесплатный вариант — GitHub Pages.

1. Создай бесплатный репозиторий на GitHub.
2. Загрузи в корень содержимое папки `rep-pwa`.
3. В GitHub открой Settings → Pages.
4. Source: Deploy from a branch.
5. Выбери `main` и `/root`, затем Save.
6. GitHub выдаст HTTPS-ссылку.
7. Открой её в Safari на iPhone.
8. Нажми Поделиться → На экран «Домой».
9. Запускай через появившуюся иконку REP.

Таня сможет открыть ту же ссылку и установить приложение себе. Данные у каждого устройства будут храниться отдельно.
