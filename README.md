# REP v11

Изменения:
- поиск больше не перерисовывает поле ввода при каждой букве, поэтому клавиатура на iPhone остаётся открытой;
- карточка упражнения всегда открывается сверху и возвращает к прежней позиции списка;
- новый сценарий создания тренировки: Создать -> название -> Готово -> каталог -> добавить упражнения -> Готово;
- существующую тренировку можно открыть, переименовать, удалить из неё упражнения и добавить новые через кнопку + Упражнение;
- шаблон можно запускать сколько угодно раз, история тренировок сохраняется отдельно.
